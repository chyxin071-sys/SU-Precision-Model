# SU 建筑精准建模

默认采用精简流程：统一参数 → 主体建模与检查 → 组件复用和细化 → 必要视图验收 → 局部修复。目标是减少含返工的总消耗，不以省 token 为由漏掉用户要求的细节或已发现的问题。

## 执行与记录

- 沿用已有 SU 连接或脚本途径；能力和当前文档确认一次，环境变化或调用失败才重查。本 Skill 不自带连接工具。
- 未实际执行的脚本不能称为模型；截图不能代替尺寸测量，运行成功不能代替验收。无法完成的检查标为未验证。
- 新建模型另存；修改已有模型保留恢复点及组织方式。交付真实文件格式，不把其他格式改名为 SKP。
- 首次集中读参考图，仅保存一份简短记录：关键尺寸及来源、单位与轴向、楼层标高、墙板/洞口关系、推测项、构件标识。参考变化或出现矛盾才重读相关图片；不反复输出长计划或全模型数据。

## 建模前锁定基准

- 尺寸区分给定、图纸标注、推导和暂定。透视图不能全图按像素等比测量；无可靠尺寸时只询问影响整体的基准，允许假设后注明比例复原。多图冲突不能静默忽略。
- 同一组参数派生墙板和洞口位置。明确楼层标高指板顶、板底还是完成面，明确外墙按轴线或墙皮定位；墙高按实际接合策略计算，不独立猜测。
- 隐藏部分延续已确认的楼层、轴网和屋顶逻辑，保留简短推测标记。不无依据镜像立面或声称真实还原。
- 默认完成主体、墙板、屋顶、主要门窗及可见立面构件。优先完成影响轮廓和观感的细节；隐藏构造仅在要求时建模，用户明确要求的精细度不得自行降低。

## 建模与检查

先核对主体，再铺开细节；检查通过自动继续，不逐阶段要求批准。

| 范围 | 默认做法 |
|---|---|
| 单位、总尺寸、楼层标高、主要退台与屋顶轮廓 | 主体完成时严格核对实际模型，错误先修复 |
| 墙板接合、悬空和异常穿插 | 按构件关系批量测量；保留覆盖数量与未检查项，仅返回异常构件、实测值及目标关系 |
| 重复门窗/开间 | 验证每种组件定义，再复用；批量检查实例数量和定位，抽查首尾、转角及特殊实例的接合与外观 |
| 洞口与实体 | 核对宿主、实际穿透和局部净尺寸；应为实体的墙板检查闭合，不要求单面玻璃等全部闭合 |
| 其他几何质量 | 批量筛查退化/重复面和反面，返回摘要；抽查失败时扩大到同类构件，不逐面向 AI 传坐标 |

- 保留楼层与构件分组，重复对象用组件；修改共享定义前确认影响范围。原始边面保持 Untagged，标签用于组/组件。
- 测量考虑嵌套实例的累计变换与局部坐标。包围盒用于初筛，不能直接判定真实碰撞、斜墙厚度或洞口净宽；允许有意的构造相交。
- 使用脚本时复用已验证函数，批量执行相互独立的同类操作，不逐对象来回调用。单位转换与未知 API 核对一次后复用，禁止猜接口。
- 容差依项目精度与参考可靠性确定；区分数值误差与图片推断不确定性，不用毫米小数伪装精度。

## 视图与局部修复

- 不每建一个构件就截图。主体阶段用一个匹配参考的视角核对轮廓；交付前默认看参考匹配视角和背面斜视。已有视图且几何未变可复用。
- 默认视角不足以覆盖参考图中的关键特征，或存在遮挡、复杂屋顶、错位疑点时，补对应侧面、顶面或局部剖面。视图数量不是硬上限。
- 只用实际模型视图验收。视觉不符先排除相机差异；实测错误即使截图看不见也要修。
- 修复参数或宿主关系的根因，仅更新受影响构件；复查改动及相邻依赖。只有改动全局参数或发现系统性错误才重查全局，不每次全楼重建。
- 同一问题连续两次修复没有改善，保留最佳版本并说明未解决原因；继续独立工作。关键错误未解决时交付状态为草稿。

## 简短交付

结束时做一次总体核对：总尺寸、楼层、问题清单和保存结果。支持时重新打开已保存 SKP 确认可读取，无须重跑全部检查。

交付 SKP 与必要视图，简短说明尺寸基准、主要推测、已执行检查及遗留/未验证项。详细信息保存在同一记录中，不重复长篇报告。轻微修改只执行相关检查，例如只改材质不重查墙板。

用户要求规范或使用尺度审查时，结合项目地区、用途和当前权威依据进行评估。
