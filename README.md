# SU Precision Model

面向 Codex 的建筑 SketchUp 精准建模 Skill。用于根据参考图建立可编辑建筑模型，并在交付前检查和修复墙板错位、洞口错误、几何问题与隐藏立面逻辑问题。

当前版本是建模质量流程，不包含 SketchUp 连接插件。可配合已具备 SU 操作能力的 Agent 使用；没有连接时不能直接生成并验证 SKP。面向用户当前的 Codex + GPT-6 Astra 工作流编写，不包含模型专属 API 或模型性能承诺。

## 安装

使用 Skills CLI：

```sh
npx skills add chyxin071-sys/SU-Precision-Model --skill su-architecture-precision
```

也可以将仓库中的 `su-architecture-precision` 文件夹复制到本地技能目录。Skill 入口是 [SKILL.md](su-architecture-precision/SKILL.md)。

## 使用示例

```text
使用 $su-architecture-precision，根据附图创建建筑 SU 模型。
已知建筑总宽为【填写】米，楼层高度为【填写】米。
需要墙体、楼板、屋顶和真实门窗洞口，保留楼层与构件分组。
不可见部分采用与已知建筑关系一致的合理推断，并记录推测。
采用默认精简流程，交付前检查墙板接合、实际尺寸和必要视图，修复后再交付。
输出 SKP、必要验收视图和检查记录。
```

没有可靠尺寸时，明确要求比例复原，避免把推断值当作精准尺寸。参考图、平面图、立面图或剖面越完整，隐藏部分的不确定性越少。

## 质量流程

1. 确认 SU 实际操作与验证能力。
2. 集中读图，保存一份精简的参数、尺寸来源及构件关系记录。
3. 先验证体量与楼层，再完成墙板、洞口和细节。
4. 批量检查主体实际尺寸与接合关系，只返回异常；重复组件先验证定义，再检查实例定位并抽查特殊位置。
5. 默认检查参考匹配视角和背面斜视；覆盖不足或有疑点时补充侧面、顶面或局部剖面。
6. 只修复和复查受影响范围，简短报告未验证项和推测部分。

默认减少重复读图、逐对象调用、全量几何返回和长报告。主体检查与用户指定精细度保留；发现系统性错误或抽查失败时扩大检查范围。轻微修改只检查相关部分。

## 验证状态与边界

当前为首版流程 Skill，尚未用真实 SketchUp 模型完成端到端验证。格式检查不代表建模质量已获实测证明。目标是减少人工返工，允许 Agent 内部多轮修复；不保证单次生成正确，不保证从单张图片准确还原未知背面，也不替代建筑规范审查和结构设计。
